🌐 Live Demo

📌 Overview

StayHub is a full-stack vacation rental and property listing platform inspired by Airbnb. Users can browse listings, view property details, create accounts, add their own properties, and manage listings through a secure authentication system.

✨ Features
🔐 User Authentication & Authorization (JWT)
👤 Secure Login & Registration
🏠 Create, Edit, and Delete Listings
📷 Property Image Management
🔎 Search and Browse Listings
🛡️ Role-Based Access Control (RBAC)
📱 Fully Responsive Design
⚡ Fast and Modern UI
🔄 RESTful API Integration

🚀 Installation
Clone Repository
git clone https://github.com/kamaljeet-sharma/StayHub.git
cd StayHub
Backend Setup
cd backend
npm install
npm run start
Frontend Setup
cd frontend
npm install
npm run dev
🔑 Environment Variables

Create a .env file inside the backend folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:5173
